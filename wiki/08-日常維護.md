# 日常維護

## 自動清理 Docker 垃圾

Docker 每次更新映像會留下舊版,累積佔用磁碟。設定每週自動清理:

```bash
# ~/cleanup.sh
#!/bin/bash
docker image prune -f > /dev/null 2>&1
docker builder prune -f > /dev/null 2>&1
```

```bash
chmod +x ~/cleanup.sh
crontab -e
# 加入:每週一凌晨 4 點
0 4 * * 1 /home/pi/cleanup.sh
```

## HA 歷史資料庫保留

HA 預設無限保留歷史,設定只留 14 天:

```yaml
# ~/ha/config/configuration.yaml
recorder:
  purge_keep_days: 14
  commit_interval: 30
```

## 磁碟空間管理

Pi 3 目前磁碟構成參考:

| 項目 | 大小 |
|---|---|
| Docker (images + 容器層) | ~8.6G |
| HA config | ~40M |
| HA DB | ~23M |

**16GB SD 卡建議升級 32GB**:空間多一倍,足夠長期使用。升級方式:

- 用 Raspberry Pi Imager / `dd` 整卡複製到新卡
- 或重燒 + 重灌(較麻煩)

## 憑證自動續期

- acme.sh 安裝時自動設定 cron(每日檢查)
- 續期成功會自動執行 `reloadcmd`(重啟 HA,幾秒鐘)
- 90 天效期,不需要手動處理

## 檢查清單(定期)

```bash
# 磁碟
df -h /

# Docker 容器健康
docker ps

# HA 網頁
curl -sk -o /dev/null -w "%{http_code}" https://<HA-IP>:8123/

# 外網
curl -sk -o /dev/null -w "%{http_code}" https://<你的網域>.duckdns.org:8443/

# 憑證到期日
openssl x509 -enddate -noout -in ~/ha/config/certs/fullchain.pem
```

## 注意事項

- HA armv7 映像停在 2025.11.3,之後不會有官方更新(功能完整但需接受)
- Pi 3 RAM 1GB 偏緊,若 HA 開始卡頓可考慮換 Pi 4/5
- SD 卡有寫入壽命,HA 的 DB 每天寫入,建議定期備份 `~/ha/config`
