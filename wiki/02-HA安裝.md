# Home Assistant 安裝 (Docker)

## 為什麼用 Docker 而非 HAOS

- 不想重刷 Pi 的 SD 卡、不影響既有容器
- 需求(整合 + HomeKit Bridge)不需要 HAOS 的 add-on 商店
- 官方支援 Docker 安裝方式

## 重要:armv7 停更對策

**踩坑紀錄**:直接 `docker run homeassistant/home-assistant:stable` 會失敗:

```
docker: no matching manifest for linux/arm/v7 in the manifest list entries.
```

原因:HA 官方在 **2025 年 5 月宣布停止 armv7(32-bit ARM)架構支援**,之後不再發布 armv7 映像。

解法:使用**最後一版官方 armv7 映像** `2025.11.3`:

```bash
docker pull homeassistant/armv7-homeassistant:2025.11.3

docker run -d \
  --name homeassistant \
  --restart=unless-stopped \
  -v /home/pi/ha/config:/config \
  --network host \
  -e TZ=Asia/Taipei \
  homeassistant/armv7-homeassistant:2025.11.3
```

> 2025.11.3 已包含官方 Xiaomi Home 整合(2024/12 推出)與 HomeKit Bridge,功能完整。缺點是之後不會再更新。

## 初始化

1. 瀏覽器開 `http://<pi-ip>:8123`
2. 建立帳號、住家名稱、時區 (Asia/Taipei)
3. 完成 onboarding

## 安裝 hass-xiaomi-miot (社群整合)

由於官方整合對台灣區支援不足,改用老牌社群整合:

```bash
mkdir -p ~/ha/config/custom_components
cd ~/ha/config/custom_components
git clone --depth 1 --branch v1.1.4 https://github.com/al-one/hass-xiaomi-miot.git xiaomi_miot_tmp
cp -r xiaomi_miot_tmp/custom_components/xiaomi_miot ./xiaomi_miot
rm -rf xiaomi_miot_tmp
docker restart homeassistant
```

> 踩坑:不要把整個 repo 當作整合目錄,要複製 `custom_components/xiaomi_miot` 子目錄。

## 驗證

```bash
# HA 網頁回應
curl -s -o /dev/null -w "%{http_code}" http://localhost:8123/
# 日誌確認整合載入
docker logs homeassistant 2>&1 | grep xiaomi_miot
```

## 藍牙錯誤

容器內日誌會出現 `habluetooth.scanner` 錯誤,這是容器無藍牙硬體的正常現象,無害可忽略。
