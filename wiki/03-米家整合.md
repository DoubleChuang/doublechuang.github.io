# 米家整合(跨區域雙帳號)

## 問題背景

- **MATE A1 新風機**:只能接入中國大陸區域米家帳號
- **小米 WiFi 插座**:台灣區域米家帳號
- 單一 HA 需要同時控制兩區設備

## 官方 Xiaomi Home 整合的限制

**踩坑紀錄**:官方整合(`Xiaomi Home`,小米 2024/12 推出)嘗試登入中國區帳號時失敗:

```
無法登入米家服務，請檢查憑證
code 70016: 登录验证失败
```

且官方文件確認:雲端伺服器只有**六個地區**——中國大陸、歐洲、印度、俄羅斯、新加坡、美國。**不支援台灣**。

結論:改用 **hass-xiaomi-miot**(社群整合),支援所有地區與多帳號。

## 在 HA 中加入整合

1. 設定 → 裝置與服務 → + 新增整合 → **Xiaomi Miot Auto**
2. 登入方式:帳號密碼
3. **地區:中國大陸** → 輸入中國區米家帳號密碼
4. 出現設備列表後,選 **Include 模式**,勾選 `MATE Air Fresh A1`
5. 家庭填入中國區家庭名稱

## 加入台灣區帳號

重複上述步驟,但:

- **地區:台灣**
- 登入台灣區米家帳號
- 勾選小米插座(此例只需電腦插座)

## 本地 vs 雲端控制模式

hass-xiaomi-miot 有三種連線模式(`conn_mode`):

| 模式 | 說明 |
|---|---|
| auto | 自動:先嘗試本地,失敗改雲端 |
| local | 強制本地 miio |
| cloud | 強制雲端 |

**踩坑紀錄**:台灣小米插座 (qmi.plug.tw02) **不支援本地 miio 通訊**,auto 模式會卡在本地發現一直失敗(實體顯示 unavailable)。

解法:把台灣區整合改為雲端模式:

```bash
# 編輯 ~/ha/config/.storage/core.config_entries
# 找到 server_country == "tw" 的 xiaomi_miot entry
# 將 data.conn_mode 改為 "cloud"
sudo docker restart homeassistant
```

而 MATE A1 (mate.airfresh.a1) **支援本地 miio**,auto 模式自動走本地(UDP 54321),控制即時無延遲。

## 驗證本地控制 (python-miio)

```python
from miio.device import Device
d = Device("<新風機-IP>", "<token>")
print(d.info())   # mate.airfresh.a1 v1.0.7 @ <新風機-IP>

from miio.miot_device import MiotDevice
mapping = {"power": {"siid": 2, "piid": 1}, "fan_level": {"siid": 2, "piid": 5}}
dev = MiotDevice(ip="<新風機-IP>", token="<token>", mapping=mapping)
print(dev.get_properties_for_mapping())   # 讀取開關/風量
dev.set_property("fan_level", 2)          # 控制風量
```

MATE A1 的 MIoT 規格(公開,miot-spec.org):

| siid | piid | 屬性 | 說明 |
|---|---|---|---|
| 2 | 1 | on | 開關 (bool) |
| 2 | 5 | fan-level | 風量 1~5 |

## token 取得方式

設備 token 儲存在 `~/.ha/config/.storage/xiaomi_miot/devices-<user>-<region>.json`,登入後自動取得。也可用 [Xiaomi-cloud-tokens-extractor](https://github.com/PiotrMachowski/Xiaomi-cloud-tokens-extractor) 從雲端提取。
