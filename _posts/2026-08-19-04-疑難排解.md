# 疑難排解(踩坑紀錄)

## 1. 米家登入 70016「登录验证失败」

**症狀**:hass-xiaomi-miot 登入中國區帳號回 `code 70016, 登录验证失败`,且 `captchaUrl` 為 null。

**原因**:小米對**國外 IP 用程式登入中國區帳號**的風控。即使密碼正確也直接拒絕,不給驗證碼。

**解法(按順序試)**:
1. **手機米家 app 解鎖**:米家 app 切到中國大陸區域,用該帳號登入一次(收簡訊驗證碼),成功後等 10~30 分鐘再回 HA 重試
2. **瀏覽器登入解鎖**:開 https://account.xiaomi.com 用同一帳號登入一次
3. 確保密碼正確(可先用米家 app 驗證)

## 2. 間歇性 Connection refused (account.xiaomi.com / sts.api.io.mi.com)

**症狀**:登入過程中隨機出現 `Max retries exceeded... Connection refused`,時好時壞。

**原因**:Pi 的 `/etc/resolv.conf` 有兩個 nameserver(路由器的 `<路由器-IP>` + 另一台設備的 `<異常DNS-IP>`),其中 **<異常DNS-IP> 偶爾回傳錯誤解析結果**(把 sts.api.io.mi.com 解析成 <異常DNS-IP>),導致連線被拒。

**解法**:改用穩定的公共 DNS:

```bash
# /etc/dhcpcd.conf 追加
static domain_name_servers=168.95.1.1 1.1.1.1 8.8.8.8

sudo systemctl restart dhcpcd
docker restart homeassistant   # 讓容器吃到新 DNS
```

驗證:解析 10 次應全部得到相同正確 IP。

## 3. 台灣插座 unavailable「Unable to discover the device」

**症狀**:qmi.plug.tw02 插座實體顯示 unavailable,日誌一直 `Unable to discover the device <插座-IP>`。

**原因**:台灣版小米插座**不支援本地 miio 通訊**(UDP 54321 無回應),auto 模式卡在本地發現。

**解法**:見 [03 - 米家整合](/posts/03-米家整合) 的「本地 vs 雲端控制模式」,將台灣區整合改為 `conn_mode: cloud`。

## 4. 插座閃橘燈 + 雲端控制失敗 (code -704042011)

**症狀**:插座燈號橘色閃爍,HA 控制回 `code: -704042011`(設備離線),ping 不到 <插座-IP>。

**原因**:插座本身 WiFi 掉線(非 HA 問題)。可能原因:路由器 DHCP 租約到期、訊號問題。

**解法**:
1. 插座斷電重插,等 1~2 分鐘重新連線
2. 若仍無法連線,在米家 app 重新配對
3. 恢復後 ping 通 + 燈號變恆亮,HA 雲端控制即恢復(雲端同步有 5~10 秒延遲屬正常)

## 5. 官方 Xiaomi Home 整合 OAuth 登入失敗

**症狀**:官方整合「無法登入米家服務,請檢查憑證」。

**原因**:小米 OAuth 風控 + 官方整合不支援台灣區。官方文件確認僅支援 6 大地區。

**結論**:放棄官方整合,直接使用 hass-xiaomi-miot(覆蓋所有地區、帳號密碼登入較穩定)。

## 6. armv7 沒有 Docker 映像

**症狀**:`no matching manifest for linux/arm/v7`。

**原因**:HA 官方 2025 年 5 月起停止 armv7 支援。

**解法**:使用最後一版 `homeassistant/armv7-homeassistant:2025.11.3`(見 [02 - HA 安裝](/posts/02-HA安裝))。

## 7. Docker 映像下載中斷

**症狀**:`docker run` 拉到一半 timeout,容器沒建立。

**解法**:分兩步執行——先 `docker pull` 確認完成,再 `docker run`(映像已在本地,秒級完成)。

## 8. .storage 權限問題

**症狀**:直接編輯 `~/ha/config/.storage/*.json` 時 `Permission denied`。

**原因**:HA 容器以 root 執行,storage 檔案屬 root。

**解法**:用 `sudo` 編輯,編輯後重啟容器:`docker restart homeassistant`。
