## Pi 3 初始狀態問題

檢查時發現 Pi 有兩個資源問題需要先處理:

### 1. RAM 被 GPU 吃掉 256MB

`/boot/config.txt` 中 `gpu_mem=256`,導致可用記憶體只剩 765MB(1GB 總共)。

```bash
# 備份後改為 64MB
sudo cp /boot/config.txt /boot/config.txt.bak
sudo sed -i "s/^gpu_mem=256/gpu_mem=64/" /boot/config.txt
sudo reboot
```

效果:765MB → 960MB 可用記憶體。

### 2. Swap 只有 100MB

```bash
sudo sed -i "s/^CONF_SWAPSIZE=100/CONF_SWAPSIZE=1024/" /etc/dphys-swapfile
sudo systemctl restart dphys-swapfile
sudo swapon --show   # 確認 1024M
```

### 3. 磁碟空間不足 (2.5GB 剩餘)

Docker 累積了 3.5GB 無用映像,先回收:

```bash
docker image prune -a -f   # 回收約 2.9GB
```

## 既有 Docker 容器

Pi 上原本已有 6 個容器在跑(go-mp4-server x5、transmission),全部設為 `restart=always`,重開機後會自動恢復,不影響 HA 安裝。

## 重點結論

- Pi 3 跑 HA(Docker)沒有問題,但需要先釋放資源
- armv7 架構注意:HA 官方已停止 armv7 支援(見下一章)
- 16GB SD 卡可用但偏緊,建議升級 32GB(見 [08 - 日常維護](/posts/08-日常維護))
