# 遠端存取 (DDNS + Port Forward + HTTPS)

人在外面也能控制 HA。方案比較過:HA Cloud 月費、Cloudflare Tunnel 需要自己的網域(duckdns 無法搬家),最終選 **duckdns + Port Forward + Let's Encrypt**。

## 架構

```
iPhone(外網)
   │  https://<你的網域>.duckdns.org:8443
   ▼
路由器 (duckdns 自動更新浮動 IP + Port Forward 8443 → <HA-IP>:8123)
   ▼
Pi → Home Assistant (HTTPS + 2FA)
```

## 1. duckdns 浮動 IP

- 到 duckdns.org 註冊免費網域(此例:<你的網域>.duckdns.org)
- 老毛子路由器 DDNS 設定填入 duckdns token,自動更新浮動 IP
- 驗證:`nslookup <你的網域>.duckdns.org` 應等於目前外網 IP

## 2. 路由器 Port Forward(老毛子)

外部網路(WAN) → 連接埠轉發:

| 欄位 | 值 |
|---|---|
| 通訊協定 | TCP |
| 外部連接埠 | 8443(非標準埠降低掃描) |
| 內部 IP | <HA-IP> |
| 內部連接埠 | 8123 |

## 3. Let's Encrypt 憑證 (acme.sh + duckdns)

使用 DNS-01 驗證,**不需開 port 80**:

```bash
# 安裝 acme.sh(含自動續期 cron)
curl -s https://get.acme.sh | sh -s email=<你的email>

# 申請憑證(變數名是 DuckDNS_Token,不是 DUCKDNS_TOKEN!)
export DuckDNS_Token="<duckdns token>"
~/.acme.sh/acme.sh --issue --dns dns_duckdns -d <你的網域>.duckdns.org --server letsencrypt

# 安裝到 HA 可讀位置,續期時自動重啟 HA
~/.acme.sh/acme.sh --install-cert -d <你的網域>.duckdns.org \
  --key-file /home/pi/ha/config/certs/key.pem \
  --fullchain-file /home/pi/ha/config/certs/fullchain.pem \
  --reloadcmd "sudo docker restart homeassistant"
```

> 踩坑:變數名稱是 `DuckDNS_Token`,用 `DUCKDNS_TOKEN` 會報「You must export variable: DuckDNS_Token」。

## 4. HA 啟用 HTTPS

```yaml
# ~/ha/config/configuration.yaml 追加
http:
  ssl_certificate: /config/certs/fullchain.pem
  ssl_key: /config/certs/key.pem
```

重啟後 **HTTP 停用,只能用 HTTPS** 存取。

## 5. 啟用 2FA(必做)

HA 已暴露公網,必須:

- HA → 使用者 → 安全性 → 兩步驟驗證 → 設定(驗證器 app)
- 密碼改強密碼

## 6. 手機設定

- HA app 伺服器位址:`https://<你的網域>.duckdns.org:8443`
- 用**行動網路**測試(關 WiFi)

## 驗證外網

從外部節點測試(如 check-host.net)確認 duckdns:8443 回 200。

## 安全性提醒

| 項目 | 狀態 |
|---|---|
| HTTPS | ✅ Let's Encrypt 自動續期 |
| 2FA | ✅ 必做 |
| Port Forward | 只開 8443 |
| OpenVPN | 保留作為備援(不開 port 最安全) |

## 其他方案比較(為何不選)

| 方案 | 結果 |
|---|---|
| HA Cloud (Nabu Casa) | 月繳 $6.5,功能好但非必要 |
| Cloudflare Tunnel | duckdns 不能搬到 Cloudflare 管 DNS,需新網域;官方 cloudflared 無 armv7 映像 |
| 純 OpenVPN | 最安全但每次要先連 VPN |
| mDNS 反射器 | 讓 HomeKit 遠端可用,hack 性質不保證(見 [06](/posts/06-HomeKit與Siri)) |
